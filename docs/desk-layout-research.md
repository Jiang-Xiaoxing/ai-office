# 阁楼新增工位布局调研

调研日期：2026-10-15。对象：`attic-bg-2` 的第 4–6 个工位。目标是在保留原背景、三张原桌及一屏 4 倍像素显示的前提下，让扩展工位属于同一个房间。

## 原画面的问题

- 原三张桌子属于阁楼背景：暖木纹、偏棕的弱轮廓、米色电脑、墨绿椅垫。新增工位来自另一套手绘图集，紫灰硬描边、屏幕与椅子的比例不同，形成明显的“贴纸”感。
- 中央横排的位置基本有空间，但旧素材的桌腿、椅背和阴影不对应背景家具，单纯挪位置不能解决风格差异。
- 原 `attic-six.png` 实际只配置了两个假工具，共五人；本次必须用三个假工具重新验收六人容量。
- 旧标签避让仅涵盖人物和新增工位，没有完整保护背景中的灯、书架、楼梯和原桌。

## 实装方案

1. **同款家具**：以背景原生 480×270 网格中的左上桌椅为来源，在素材构建脚本中用透明轮廓提取桌面、电脑、书、盆栽、桌腿及椅子。保持原像素颜色与尺寸，家具以外透明，落地阴影单独绘制。背景 PNG 本身不改。
2. **成组与留白**：第 4–6 人继续使用中央同向横排，座位为 `(176,179)`、`(260,179)`、`(344,179)`，间距 84 原生像素。保持原三人的席位、外观和背景家具位置。
3. **容量与空位**：席位由配置绑定，只有对应工具存在才画新增桌椅；工具空闲时桌椅保留、人去休息。删配置后才移除该席位家具。没有工具的预留席位保持原来的木地板。
4. **空间约束**：新增家具、椅子及行走占地统一测量；楼梯、沙发、落地灯、书架、窗、吊灯和绿植使用保护区域。标签也避让家具；不能用标签遮住楼梯来换取排版空间。
5. **像素与光线**：沿用原生整数坐标、最近邻显示和 1920×1080 下的 4 倍整数放大。新家具进入同一场景再接受现有天气光线，避免成为独立发亮的一层。

## 验收

- 原背景文件与选定参考图保持逐字节一致；原三席的坐标、外观和正常三人工况保持原有行为。
- 现有检测、办公室、标签、天气、动态人数、截图及私人小站入口检查均执行；新增六人工位保护区、休息路径与素材透明边界检查。
- 临时向 `config/tools.json` 加入 A/B/C 三项测试工具，以实际存在的 `explorer.exe` 检测为干活，重启真实后端后截 `preview/attic-six.png`。不用浏览器伪造六人接口。
- 保存原始配置字节，验收后原样恢复并核对 SHA-256，再次重启，截正常状态 `preview/attic-work.png`。两图为 1920×1080；只在截图浏览器固定晴天时刻以便核对家具，生产时钟不变。
- 后端隐藏窗口运行且 `127.0.0.1:8889` 可用；只做本地简体中文 Git 提交，不提交 `preview/attic-bg-1.png`。
