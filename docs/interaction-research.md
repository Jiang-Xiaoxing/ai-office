# 像素阁楼互动调研与取舍

调研日期：2026-10-15。范围是独立、开源、仅监听 `127.0.0.1` 的 AI 状态看板。此次用户明确授权自行选型并直接实装；保持现有阁楼背景、480×270 网格、1920×1080 下的 4 倍整数缩放，以及天气、人物动作和真实状态同步。

通过 agent-reach 的 GitHub CLI 搜索定位项目，再用其 Jina Reader 路线阅读项目与作者文档。直连和单命令代理均实测可达，实际阅读使用直连；没有安装额外工具或导入第三方素材。

## 选择并实现的三项

1. **和伙伴打招呼、查看状态。** 点击人物，或用 Tab 聚焦人物后按 Enter/空格。顶部短消息显示完整工具名字、当前干活/空闲状态与一句本地预设回应，人物上方出现像素爱心。工作中的伙伴继续敲键盘、行走中的伙伴继续原路线；同步状态变化时消息跟着更新。断线时明确标成上次状态。反馈不是 AI 对话，不启动工具或调用模型。
2. **给绿植浇水。** 点击场景左侧、中央或右下角的大盆栽，或点击顶栏“浇水”照料三盆。盆栽出现短暂像素水滴，并显示浇水反馈；同一盆短时间内重复点击会提示已经浇过，避免特效堆叠。不设置每日任务、积分、枯萎或持久存档。
3. **泡一壶茶。** 点击左下茶桌，或点击顶栏“泡茶”。桌上出现像素茶杯和短暂热气，提示茶已泡好。不会把忙碌伙伴强制拉来喝茶，不改变底栏状态。重复触发有短暂冷却。

空白处点击、Escape 或消息关闭按钮可收起反馈；消息也会自动消失。全部入口支持键盘，场景入口按画布投影跟随窗口缩放；减少动画偏好保留静态反馈。

## 视觉与实现边界

- 沿用现有深青 `#233b47`、米白 `#f0e3ce`、植物绿 `#a5cbb7`、茶色 `#dfbd8a` 和爱心粉 `#e5a48b`，沿用微软雅黑与现有字体层级。
- 顶栏只增加“浇水”“泡茶”两个轻按钮；回应放在顶栏下的屋顶区域。人物和物件本身就是入口，不新增常驻侧栏，不压缩画布。窄屏沿用原有上下栏占位逻辑。
- 特效直接画在原生像素画布上，坐标取整，再随现有整数倍放大；文字与可访问按钮用 HTML。
- 互动层独立于天气、寻路与状态检测；不写配置、不新增后端写接口、不访问外网、不保存会话或密钥、不修改系统设置。
- 不采用布局拖拽/人物搬家（会影响已选背景与寻路）、强制休息/修改工作状态（状态含义失真）、完整桌宠养成与抛球（增加角色与路径复杂度）、联网聊天/通知声音（额外依赖或打扰）。参考项目只提供交互思路，未复制代码或素材。

## 验证要求

保留现有检测、天气、六人工位、标签避让、窄屏与 `/office/` 前缀回归。新增浏览器测试覆盖鼠标/键盘入口、真实状态优先、断线提示、冷却/特效上限、缩放命中、减少动画、名单变更和本地资源。统一测试运行器使用临时回环端口及本 worktree，隐藏运行测试服务并在结束时关闭，不操作 8889。互动交付截图为 `preview/interaction-*.png`，1920×1080，并逐块检查未被 HTML 覆盖的 4×4 像素。
